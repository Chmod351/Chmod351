## 🚀 Featured Project

### 📡 **Radar — External Attack Surface Monitoring Platform**
A multi-tenant external attack surface management platform featuring a Next.js/React executive dashboard, a Bun/TypeScript API, and a containerized reconnaissance worker[cite: 2].

* **Architecture:** Decoupled scan orchestration enforcing multi-tenant ownership, RBAC permissions, and isolated worker task dispatch[cite: 2].
* **Security:** Secured API-to-Worker communication using timestamped **HMAC-SHA256 signatures** to authenticate commands and prevent replay attacks[cite: 2].
* **Streaming:** Asynchronous ingestion pipelines with **Server-Sent Events (SSE)** and webhooks for real-time target discovery and live telemetry[cite: 2].
* **Tech Stack:** TypeScript, Bun, Node.js, Next.js (App Router), React, Docker, PostgreSQL, AWS (ECS/Fargate), Security Tooling (Subfinder, Nmap, etc.)[cite: 2].
